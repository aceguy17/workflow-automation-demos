# Workflow Automation Demos

Interactive demos of AI workflow automations for small businesses, built by Irfan.

| Demo | What it shows |
|---|---|
| [AI Lead Qualifier](lead-qualifier.html) | Enquiry → AI extract and score → CRM → Slack alert → reply draft |
| [Invoice Capture](invoice-capture.html) | Emailed invoice → AI extract → GST, totals and ABN checks → duplicate check → bills register |
| [Meeting Notes → Tasks](meeting-actions.html) | Transcript → summary, decisions, risks → tasks with owners and due dates → follow-up email |
| [Support Triage](support-triage.html) | Ticket → customer lookup → category, urgency, tone → priority and routing → reply draft |

These are personal demos with fictional businesses and data. The AI steps are simulated in the browser with rule-based logic, so they run without an account and nothing typed leaves the browser. Client builds use n8n, Make or Zapier with an LLM API and the client's real systems.

Static site: plain HTML, CSS and JavaScript, no build step.
